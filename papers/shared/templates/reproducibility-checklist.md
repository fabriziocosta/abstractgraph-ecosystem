# Reproducibility Checklist

- [ ] Exact code revisions are recorded.
- [ ] Environment and dependency versions are captured.
- [ ] Dataset sources, licences, versions, and processing are recorded.
- [ ] Immutable data splits are provided.
- [ ] Every experiment has a versioned configuration.
- [ ] Random-seed policy is documented.
- [ ] Baseline tuning budgets are comparable.
- [ ] Raw results are retained separately from derived outputs.
- [ ] Tables and figures can be regenerated by documented commands.
- [ ] Runtime, hardware, and peak memory are reported.
- [ ] Failed and excluded runs are recorded.
- [ ] Main claims link to supporting artifacts.
