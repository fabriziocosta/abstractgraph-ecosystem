# Shared Paper Resources

This directory contains resources that must remain consistent across the
AbstractGraph paper series. Paper-specific decisions belong in the relevant
paper directory; changes here potentially affect every paper.

## Contents

- `terminology.md`: canonical vocabulary and usage rules.
- `notation.md`: mathematical symbols and representation invariants.
- `claim-ledger.md`: programme-wide mapping from claims to evidence.
- `datasets.md`: dataset registry and split policy.
- `benchmarks.md`: baseline, metric, and comparison rules.
- `references.bib`: shared bibliography database.
- `templates/`: reusable manuscript and reproducibility templates.

Every shared change should be recorded in the decision log in
[`../PLAN.md`](../PLAN.md).
