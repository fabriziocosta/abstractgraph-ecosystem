\section{Evaluating Structural Discrimination}
\label{sec:experimental-protocol}

The evaluation follows the paper's argument rather than the full software
surface. It asks whether established representations are reproduced faithfully,
which distinctions alternative expressions preserve, what genuine composition
changes relative to strong flat controls, whether the change can be localized,
and what it costs. Pooling, reserved features, diagnostic probes, and bounded
hashing are reported separately in \cref{app:supplementary-results} because
they concern vectorization after an operator program has run.

\subsection{Controlled Structural Contrasts}

The primary synthetic family composes cycles, paths, and star-like rays while
recording its generating parameters. Each graph is paired with identifier
permutations that must remain equivalent and with verified non-isomorphic
single-factor interventions. Hard pairs additionally match node count, edge
count, degree distribution, density, and label histogram. Operator expressions
and pair-selection rules are frozen before confirmatory evaluation. Held-out
parameter ranges and structural combinations test whether conclusions extend
beyond the examples used to choose the expressions. ZINC supplies natural
structural frequencies and scaling measurements, not causal contrasts.

For expression $P$, let $\Sigma_P(G)$ denote its unbounded structural signature
before bounded hashing. On verified non-equivalent pairs $\mathcal Q_f$ for
factor $f$, intrinsic discrimination is
\begin{equation}
 D_f(P)=\frac{1}{|\mathcal Q_f|}
 \sum_{(G,H)\in\mathcal Q_f}
 \mathbf{1}[\Sigma_P(G)\ne\Sigma_P(H)].
\end{equation}
We report the vector $(D_f(P))_f$ rather than use one aggregate score as an
expressivity ranking.

\subsection{Graph-Kernel Coverage and Faithfulness}

We audit six established feature families: vertex and edge histograms,
shortest-path kernels \cite{Borgwardt2005ShortestPath}, graphlet kernels
\cite{Shervashidze2009Graphlet}, WL subtree features
\cite{Shervashidze2011WeisfeilerLehman}, and NSPDK
\cite{Costa2010NSPDK}. Each receives one of three statuses: \emph{faithful},
when an AG program agrees with an independent implementation; \emph{bounded
proxy}, when the language constructs a declared restricted feature family; or
\emph{not currently native}, when a required operation is absent.

The distinction is strict. Radius-bounded graphlet enumeration is not called an
exact graphlet kernel until sampling and enumeration semantics match. A
shortest-path construction must encode endpoint attributes and distance rather
than merely hash the induced path. Radius-bounded neighborhood hashing is
recorded as a WL-like proxy because it follows the same local-identity histogram
principle; exact WL status additionally requires parity with iterative multiset
relabelling. NSPDK additionally requires rooted
neighborhoods, radius, distance, ordered-pair semantics, and multiplicity. The
faithfulness checks compare feature identities and multiplicities, graph-pair
decisions, and kernel or vector values where applicable. Failed candidates
remain informative coverage boundaries rather than approximate successes.

\subsection{Composition and Strong Flat Controls}

The operator notebooks expose two different comparisons. Additive programs run
several decompositions on the same input. Under lossless identities and matching
multiplicity, their vectorization should agree with concatenating the branch
vectors; this equality is a validation test, not a compositional advantage.
Ordered and relational programs are different: a later operator acts on mapped
objects or relations produced earlier.

We therefore compare each program with four controls:
\begin{enumerate}
  \item its atomic branch signatures;
  \item lossless concatenation of those signatures;
  \item a flat relational materialization containing the same candidate derived
        objects and tuples available to the composed program; and
  \item the graph-valued composition before vectorization.
\end{enumerate}
The third control prevents us from claiming that an interpretation graph has
greater discrimination than an unrestricted flat encoding of the same
information. A useful compositional result may instead be a distinction absent
from atomic concatenation, faithful agreement with the flat materialization,
and better localization or cost from retaining the derived objects in one
mapped representation.

\subsection{Mapped-Witness Evaluation}

For every representative separation, the analysis retains the interpretation
nodes whose identities differ and maps them to base nodes and edges. Witnesses
are evaluated against the known synthetic intervention using node and edge
precision, recall, and intersection-over-union. Comparisons include random
frequency-matched subgraphs and provenance retained by the corresponding flat
materialization. Thus the experiment tests the specificity of AG localization,
not merely the fact that AG stores a mapping.

\subsection{Discrimination--Complexity Trade-offs}

Every atomic, concatenated, flat-materialized, and graph-composed configuration
is charged for end-to-end decomposition, identity construction, vectorization,
and provenance storage. Measurements include wall time, peak memory,
interpretation or flat-object size, sparse nonzeros, serialized size, and
failure boundaries. We report separate factor-specific
discrimination--runtime, discrimination--memory, and discrimination--size
frontiers with repeated-run uncertainty. Aggregate discrimination is secondary
because it can hide incomparable profiles.
