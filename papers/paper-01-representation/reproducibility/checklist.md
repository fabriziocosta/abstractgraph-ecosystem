# Paper 1 Reproducibility Checklist

This checklist specialises the
[`shared checklist`](../../shared/templates/reproducibility-checklist.md).

- [ ] Exact `abstractgraph` revision is recorded.
- [ ] Dirty-worktree state and any patch are captured.
- [ ] Supported Python and dependency versions are recorded.
- [ ] Synthetic generators and parameters are versioned.
- [ ] Reference graph fixtures are immutable and checksummed.
- [ ] Every operator program has a serialised specification.
- [ ] Permutation generation and attribute preservation are documented.
- [ ] Identity equivalence and collision criteria are fixed.
- [ ] Baseline implementations and budgets are fixed.
- [ ] Scaling hardware and measurement method are reported.
- [ ] All figures and tables identify their source run IDs.
- [ ] Claim ledger entries link to final evidence.
